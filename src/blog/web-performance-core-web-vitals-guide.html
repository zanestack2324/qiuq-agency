Core Web Vitals: How to Score 90+ on Google PageSpeed

Published July 2026  |  7 min read

Google uses Core Web Vitals as a ranking factor. A slow website doesn't just frustrate users it actively pushes you down in search results. Here's how to fix it.

What Are Core Web Vitals?

Core Web Vitals are three metrics Google uses to measure user experience:

LCP

Largest Contentful Paint how fast the main content loads. Target: under 2.5s.

INP

Interaction to Next Paint how responsive the page feels. Target: under 200ms.

CLS

Cumulative Layout Shift visual stability. Target: under 0.1.

Quick Wins for Better Performance

1. Optimize Images

Images are the #1 cause of slow websites. Use WebP format, compress aggressively, and lazy-load everything below the fold.

2. Minimize JavaScript

Every KB of JavaScript delays interactivity. Code-split, tree-shake, and defer non-critical scripts.

3. Use a CDN

Content Delivery Networks serve your assets from the closest server. Vercel, Cloudflare, and AWS CloudFront all offer great free tiers.

4. Preload Critical Resources

Fonts, hero images, and critical CSS should be preloaded. This eliminates the "flash of invisible text" and speeds up LCP.

5. Fix Layout Shifts

Always set explicit width/height on images and videos. Use CSS `aspect-ratio` for responsive elements. Reserve space for ads and embeds.
